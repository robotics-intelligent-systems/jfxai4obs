# Open Banking System

Swedbank PSD2/Saturn Interface. Decentralized banking system on the Solana blockchain (SOLs). Anchor is a feature rich, open-source, Antelope Wallet. Manage SEPA (Single Euro Payments Area) Credit and Debit Transfer. jank is a Clojure dialect. CALM AI Tools. OpenZeppelin Contracts. Enso Analytics is a workflow-based data preparation platform. The OpenCBS Loan Origination Solution manages loan application, underwriting and approval based on the workflows of financial institutions. Mifos X Web App is the Web-UI component of Mifos X. It currently uses Apache Fineract as the backend. Frappe Lending is a comprehensive Loan Management System (LMS). The FINOS Common Domain Model (CDM). The Banking Industry Architecture Network (BIAN). CashMan Financial Banking System. PyFinTS is a pure-python implementation of FinTS, a online-banking protocol. The Open Bank Project is an open source RESTful API platform for banks that supports Open Banking, XS2A, PSD2 and Open Finance. Waltz is an open-source Enterprise Architecture platform that enables organizations to visualize and define their technology landscape. FDC3 is an open standard for applications on financial desktop. Fluxnova is a flexible framework for workflow and process automation. Hibiscus is a free online banking application for Linux. FinRobot in an open-source AI agent platform for financial analysis using LLMs. PIXIU project is designed to support the development, fine-tuning, and evaluation of Large Language Models (LLMs) in the financial domain. hyperswitch is a composable, open source payments platform. Bigcapital is financial accounting with intelligent reporting. Claude for Financial Services. Agentic workflow for COBOL Reverse Engineering. The Hercules Hyperion mainframe emulator. The API Mediation Layer (API ML) provides a single point of access for mainframe service REST APIs. COBOL 4J is a COBOL compiler. CICS/COBOL implementation of Cash Account. Cobrix - COBOL Data Source for Apache Spark

The directory structure includes a specific folder for each phase of development and engineering programs:

- __MBSE__: The root folder Arcadia (ARChitecture Analysis and Design Integrated Approach) is a method of tools dedicated to systems engineering and architecture, supported by the Capella modeling tool.    
  - __CAD__: For computer-aided design.
  - __CAM__: Dedicated to the part manufacturing and assembly process.
  - __CAS__: For simulation of end-to-end functionality and performance analysis.
